## 用途与命名约定

- `photo-real-bright.jpg` / `photo-real-dark.jpg` 是**真实照片**样张；自绘 SVG
  基准（山水与光、亮调插画、暗调插画）用于可复现的稳定基线，两类素材在
  实验室与对照舞台中分开命名，不再混称“照片”。
- 对照舞台（Popover/Menu/Select/Dialog/Sheet）默认提供这三类背景切换。
