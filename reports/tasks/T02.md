## 发现的问题与处理

1. **pnpm 12 配置迁移**（ADR-0002）：`onlyBuiltDependencies` 失效 → `allowBuilds`；minimumReleaseAge 政策拒绝过新包（motion@13.5.0、vite@8.3.2）→ 自动 exclude 列表。
2. **Vite 8 lib 模式禁 CSS 入口**（ADR-0003）：`cssCodeSplit:false` 与 CSS input 冲突 → JS/CSS 分离构建 + 拷贝脚本；vite 清空 dist 导致 .d.ts 丢失 → 调整构建顺序。
3. **MCP SDK 2.2.0 API 变化**（ADR-0004）：serveStdio 改 factory、inputSchema 推荐 `z.object`、包名拆分。
4. **Storybook 10.6 docgen 选项位置**：`reactDocgen` 必须位于 `typescript` 键下；顶层写法被静默忽略且 TS 类型报错。
