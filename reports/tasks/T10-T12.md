# T10 Overlay 基础 + T11 Dialog + T12 Sheet

状态：T10/T11 verified（jsdom 行为）；T12 implemented（拖拽手感待浏览器实测）
模型：glm-5.3-flash · 日期：2026-10-02

## T10 结果

- Base UI 1.8.0 确认为唯一 headless 行为源（焦点陷阱/Escape/滚动锁/焦点恢复/嵌套栈）。
- `OverlayPortalScope`：portal 内容继承 Provider 主题/材质/动效/密度属性；
  CWA 组件的 Portal 统一走 `CwaProvider.portalContainer`。
- Overlay CSS：backdrop scrim 淡入淡出、进出只动 transform/opacity、reduced-motion 降级。

## T11 结果（Dialog）

- Compound API：`Dialog`（Root）+ Trigger/Content/Title/Description/Close。
- `DialogContent`：Backdrop + Popup；材质 glass-thick（默认）或 solid（玻璃层上浮层强制实色，
  防 glass-on-glass）。
- Trigger/Close 用 Base UI `render` prop 组合 CWA Button（React 19 下的标准组合方式，
  不产生嵌套 button）。
- onOpenChange 签名为 `(open, details)`（Base UI 2.x 形态）。
- a11y 说明：`design/components/dialog.md`。

## T12 结果（Sheet）

- Compound API：`Sheet`（Root：open/defaultOpen/onOpenChange/placement bottom|end）+
  Trigger/Content/Close/Title/Description。
- 拖拽：外层 Popup CSS 做进出（translateY/X + opacity），内层 motion.div 承接拖拽
  （transform 分层不冲突）；拖动 ≥96px 或速度 >700px/s 关闭；否则 sheet 预设
  （bounce 0.15 / 0.35s）从当前位置带速度复位；reduced-motion 瞬时复位（保留跟手）。
- Alpha 范围（按任务清单允许）：单展开位 + 拖动关闭；多 snap points 明确为后续 API。
- 已知限制（写明，不冒充完成）：内容滚动与拖拽冲突的精细化（滚到顶才拖）未实现；
  RTL 侧滑拖拽方向镜像未实现；pointercancel/capture 丢失未在真实指针验证。
- a11y 说明：`design/components/sheet.md`。

## 关键实测记录

1. Base UI Dialog 在 jsdom 下 Escape 关闭、焦点恢复、快速重开全部可用（先用最小 fixture 定位，
   再接入 CWA 包装层）。
2. `Dialog.Trigger` 内直接嵌 Button 会产生嵌套 button（a11y 违规）——必须用 `render` prop。
