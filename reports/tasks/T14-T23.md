## 已知环境限制（如实记录）

- jsdom 不派发图片 load 事件：Avatar 带图回退时序（Base UI 300ms 防闪烁）只能浏览器验证。
- Base UI popup 全局 store 在 jsdom 下跨用例有时序噪声：Select 测试统一用键盘打开保证确定性。
- Toast Close 按钮被 Base UI 标记 aria-hidden（读屏经手势/Escape），测试走 DOM 点击验证鼠标路径。
