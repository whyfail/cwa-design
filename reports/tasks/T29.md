# T29 MCP 正式只读工具集

状态：verified · 模型：glm-5.3-flash · 日期：2026-10-03

## 结果

`@cwa-design/mcp` 从 spike（1 工具）扩展为方案 §15.2 的完整 8 工具只读集：

| 工具 | 数据源 | 关键行为 |
| --- | --- | --- |
| get_capabilities | manifest | 版本/组件数/工具清单 |
| search_components | manifest | query 过滤 id/name/material/a11y；limit≤50；cursor 分页 |
| get_component | manifest | 完整契约；sections 可选（api/a11y/material/examples） |
| get_example | manifest | 已编译示例 + contentDigest |
| get_tokens | tokens dist | primitive/semantic-light/semantic-dark/motion 分组 |
| get_recipe | manifest | Alpha 无 recipes → 明确 INVALID_INPUT（不伪造） |
| plan_installation | — | 可审查安装计划，无写入 |
| get_migration | — | 同版本返回空 changes；跨版本 INVALID_INPUT（无记录不编造） |

## 纪律

- 错误统一 RegistryError → tool error（isError=true）：VERSION_NOT_FOUND / COMPONENT_NOT_FOUND /
  INVALID_INPUT / UNSUPPORTED_FRAMEWORK / REGISTRY_UNAVAILABLE。
- 离线优先：本地快照缺失报 REGISTRY_UNAVAILABLE，不静默联网。
- 无写工具、无命令执行；stdout 仅协议数据。
- 工具结果同时含 content（TextContent JSON）与 structuredContent（同一数据），legacy host 可用。
